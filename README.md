# End-to-End Customer Churn Prediction with ANN

## Project Overview

This project is an End-to-End Deep Learning application developed using **Artificial Neural Networks (ANNs)** to perform both **customer churn classification** and **estimated salary regression**.

The project demonstrates how deep learning models can be integrated into a practical machine learning workflow, from data preprocessing and feature transformation to model prediction and deployment.

The application provides two prediction tasks through a single **Streamlit web application**:

- **Classification:** Predict whether a customer is likely to churn.
- **Regression:** Predict the customer's estimated salary.

Separate preprocessing objects are maintained for each model to ensure that user input is transformed consistently with the data used during model training.

## Application

The trained ANN models and preprocessing components are integrated into an interactive Streamlit application, allowing users to enter customer information and receive predictions in real time.

The application is divided into two tabs:

**Classification** $\Rightarrow$ Customer Churn Prediction

**Regression** $\Rightarrow$ Estimated Salary Prediction


## Project Purpose

The main purpose of this project is to demonstrate an end-to-end **Deep Learning and Machine Learning deployment workflow**, combining ANN model development, preprocessing, model persistence, and interactive web-based inference in a single application.
